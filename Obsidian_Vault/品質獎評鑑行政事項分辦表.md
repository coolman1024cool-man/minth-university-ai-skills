# 🏆 卓越經營品質獎現場實地評審行政事項分辦表

> **評鑑日期**：2026年9月15日（二）
> **事前籌備**：2026年9月14日（一）前完成
> **核心地點**：圖書館主會場、研發長辦公室、各系所站點

---

## 📅 9/14 (含) 前應完成事項【事前籌備清單】

- [ ] **車輛調派預約** [[綜合行政處 (環安事務組)]]
  - 預約 9/15 高鐵接送之公務車（9人座）及司機。
  - 發送車輛調派申請單完成程序。
- [ ] **飲品訂購確認** [[USR 中心]]
  - 聯繫外訂廠商，確認 9/15 上午桶裝咖啡與茶飲的配送時間與發票統編。
- [ ] **午餐餐食訂購** [[USR 中心]]
  - 確認午餐菜色與單價並完成訂購。
  - 評審委員：**8 人份 Pizza**。
  - 工作同仁：**35 份 ok便當**。
- [ ] **設備借用** [[USR 中心]]
  - 於 9/15 前一天至研發長室借用螢幕，並妥善放置於圖書館展示中心。
- [ ] **主管名冊準備** [[綜合行政處 (人事組)]]
  - 準備全校行政一、二級主管清冊（不含教學單位）。
  - 送副校長核定，以供評審委員現場圈選。
- [ ] **桌牌與座位佈置** [[USR 中心]]
  - 製作所有與會受評主管與評審委員之姓名立體桌牌。
  - 排定座位圖並提前於會場擺設完畢。
- [ ] **會後餐點預訂** [[USR 中心]]
  - 準備/預訂新美珍蛋糕（共 4 份，一式兩盒）。

---

## 📅 9/15 當日應完成事項【現場執行清單】

- [ ] **交通接送** [[綜合行政處 (環安事務組)]]
  - **08:25** 前往高鐵新竹站接送評審委員至校。
  - **17:15** 會後專車將評審委員送回高鐵站。
- [ ] **車輛引導與跑馬燈** [[綜合行政處 (環安事務組)]]
  - 校門口引導 [[鄭春生委員]] 車輛至圖書館貴賓停車區。
  - 警衛室跑馬燈全天顯示歡迎詞。
- [ ] **茶水飲品供應** [[USR 中心]]
  - 於圖書館二樓主會場放置大桶裝飲品，供委員與與會同仁自由取用。
- [ ] **簡報計時** [[品質團隊 / 杜淑美]]
  - 負責現場簡報倒數計時：校長簡報 **35 分鐘**，其他簡報者各 **15 分鐘**。
- [ ] **午餐供餐** [[USR 中心]]
  - 安排於「研發長辦公室」用餐，並負責後續單據核銷。
- [ ] **實地審查接待** [[系所主任]]
  - 各站點實地審查接待：
    - 餐飲系：[[徐雯珊主任]]
    - AI能源中心 + ESG教室：[[吳仁明主任]]
    - 智慧製造工程系：[[于善淳主任]]
- [ ] **主管訪談名單確認** [[綜合行政處 (人事組)]]
  - 協助委員於當日圈選出下午 **14:45~15:15**「員工懇談」之受訪名單。
- [ ] **晤談室場地與協助** [[巫宜櫻主秘]] [[大美]] [[正彥]] [[珮茹]]
  - 設置 3 間獨立晤談室。
  - 規劃負責：巫宜櫻主秘。
  - 專人協助（各負責 1 間協助個別訪談進行）：大美、[[正彥]]、珮茹。
- [ ] **會後餐點發送** [[USR 中心]]
  - 於 **16:30** 前備齊會後餐點（新美珍蛋糕），發送給評審委員致意。
