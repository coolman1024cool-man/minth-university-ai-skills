# ALLTOP 經費核銷自動化機器人 (alltop-expense-bot)

## 技能觸發時機
當使用者上傳「發票」、「收據」照片，並要求進行「經費核銷」、「報帳」或「填寫核銷單」時，請啟動此技能。

## 常用標準品名命名規範 (使用者指定慣例)
在萃取單據品名或寫入「使用說明(品名)」欄位時，請統一使用簡潔標準的行政科目名稱，切勿使用冗長敘述：
1. **鐘點費**（演講、授課等，統一使用「鐘點費」3個字，勿寫專題演講鐘點費）
2. **`*月工讀費`**（例如：`8月工讀費`、`9月工讀費`）
3. **膳食費**（便當、餐盒、茶點等）
4. **交通費**（車票、高鐵、計程車等）
5. **保險費**（平安險、活動險等）
6. **材料費1**、**材料費2**、**材料費3**...（多筆耗材依序編號）
7. **影印費** / **印刷費**
8. **雜支** / **文具用品**

## 核心情境設定

### 情境 A：演講鐘點費 / 工讀金 / 工作費 / 兼職酬勞（★ 付款兼所得 ★）
- **付款類別**：`付款兼所得` (系統代碼: `IsPay = 3`)
- **所得類別**：
  - `50-薪資及兼職所得、獎(勵)金` (系統代碼: `salkind = 1`) -> 工作人員費、行政工作費、工讀費
  - `9B-演講費、稿費、論文指導費` (系統代碼: `salkind = 10`) -> 專題演講鐘點費
  - `0-不扣稅所得` (系統代碼: `salkind = 0`) -> 特殊免稅款項
- **付款對象身分**：`校外人士` (身分證字號) 或 `教職員` (人事代號) 或 `學生` (學號)
- **所得稅率**：依稅法規定 (預設 `0%` 或依身分扣繳)

### 情境 B：直接付款給廠商 (採購貨款 / 發票 / 免用收據)
- **付款類別**：`付款資料` (系統代碼: `IsPay = 1`)
- **付款對象身分**：`廠商`
- **受款人代號**：填寫收據或發票上的 `廠商統編` (8 碼)

### 情境 C：教職員一般代墊款 (郵資、文具、軟體訂閱費、影印等代墊款)
- **付款類別**：`付款兼所得` (系統代碼: `IsPay = 3`，依學校 ALLTOP 會計系統規範，教職員代墊款統一選取付款兼所得)
- **所得類別**：`0-不扣稅所得` (系統代碼: `salkind = 0`，代墊款不列入個人所得稅)
- **付款對象身分**：`教職員`
- **受款人代號**：填寫人事代號 (例如 `87023`、`PT90016`、`1122018`) 或姓名查詢選定

## 憑證類別判讀標準
1. **發票**：若單據為「電子發票證明聯」或「二/三聯式統一發票」，萃取 2 碼英文 + 8 碼數字作為 `發票號碼`，填報時需輸入發票號碼、統編、日期與金額。
2. **免用統一發票**：若印有「免用統一發票收據」字樣，`發票號碼` 留空，填報時輸入統編、日期、品名與金額。
3. **其他相關憑證**：簽收單、計程車收據等其他單據。
