# ALLTOP 採購自動化助手 (ALLTOP Purchasing Bot)

本技能旨在協助使用者快速將廠商估價單（如思渤科技等）轉化為學校 ALLTOP 系統的採購明細，並連動自動產生官方標準的 A2 規格表。

## 觸發時機 (When to trigger)
當使用者上傳廠商估價單（PDF 或圖片），並指示「建立採購案」、「合併為一式」或「分開列出採購明細」時，請啟動此技能。

## 作業流程 (Workflow)

1. **資料解析與整併**：
   - 根據使用者的指示，將估價單內的品項提取出來。
   - 若使用者要求「合併成 1 式」，請將所有規格合併為多行字串，總數量為 1，單位為「式」，單價為「含稅總額」。
   - **若該品項沒有規格可作為規範，請直接在「規格」欄位填入「無」，切勿留空。**

2. **自動寫入 RPA 專用表**：
   - 使用 Python 的 pandas 套件，將整理好的資料直接寫入使用者的 RPA 執行檔中。
   - 目標檔案路徑：`D:\01邱正彥1130801-\01經費\06未結案\ALLTOP_採購自動化工具\採購自動化專用表.xlsx`
   - 必填欄位：品名, 規格, 用途及說明, 計量單位, 數量, 單價。

3. **引導使用者執行自動化**：
   - 在完成資料寫入後，請回報使用者已更新完畢。
   - 提醒使用者前往 `D:\01邱正彥1130801-\01經費\06未結案\ALLTOP_採購自動化工具\` 目錄下：
     1. 點擊 **點我執行網頁自動填單.bat**：啟動網頁自動填表 RPA 機器人。
     2. 點擊 **點我自動生成A2表單.bat**：自動讀取 Excel，並於 A2產出結果 目錄下生成符合全域規範（標楷體、上下 2cm 邊界、USR中心、徐佳琪）的 A2 規格表。
     3. 手動將生成的 A2 規格表上傳至系統附件區。

## 注意事項
- 更新 Excel 時，請務必處理好字串的換行符號（\n），以利 RPA 機器人正確複製貼上。
- 切勿更動 .bat 與 .py 等本機自動化腳本的原始碼，除非使用者明確要求修正速度或點擊邏輯。
