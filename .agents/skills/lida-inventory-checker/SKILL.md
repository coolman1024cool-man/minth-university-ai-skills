# 立達鋼鐵庫存盤盈虧自動核算機器人 (lida-inventory-checker)

## 📌 技能定位與業務背景
本技能專門為立達鋼鐵（湖口2廠／2F）之「年終實體盤點與庫存對帳」作業設計。
每年 12 月（特別是 12/19 前後），現場盤點完畢後會產出「現場盤點表」（通常以訂單格式記錄，如 `2F訂單.xlsx`），需要與 ERP 導出的「系統庫存量表」（如 `2F 1219庫存.xlsx`）進行全面核對。

### ⚠️ 最核心原則方針（最高指導原則，嚴禁違背！）
1. **嚴禁產出公文格式 Word 檔、樞紐分析長篇大論或管理學分析**。現場生管與行政人員只需要最直覺的 Excel 表格。
2. **永遠遵循文欣（老婆）的專用版面結構**：
   - **分頁一：`⚠️ 盤盈虧差異清單(只看有差的)`**：517 項完全吻合（差額為 0）的項目自動排除，只列出數量不符的項目，標明帳面支數、現場支數、差額與哪裡多/哪裡少。
   - **分頁二：`2F完整庫存表(自動填S與T欄)`**：完全保留原本 `2F` 工作表格式，自動填入 **S 欄（現場盤點支數）** 與 **T 欄（盤盈虧公式 `=S-N`）**，有差異的項目整行以**淺黃色高亮**標記。
3. **輸出路徑規範**：
   - 存入 `E:\我的雲端硬碟\Gemini_Spark_產出檔案\`。
   - 檔名固定採用：`2F庫存盤盈虧自動核算表(老婆極簡版)-[民國年月日時分11碼]-anti.xlsx`。

## 📋 輸入資料結構對照說明
1. **系統庫存量表 (如 `2F  1219庫存.xlsx`)**：
   - 工作表名稱：`2F`
   - Column D：產品代碼（如 `BHA0005-1088`）
   - Column G：產品規格（如 `BHA*150*150*7*10`）
   - Column H：長度（如 `4.446`）
   - Column K：庫位名稱（如 `湖口2廠`、`2廠加工庫`、`皆豪J`）
   - Column N：**期末數量（即系統帳面支數）**
   - Column S：**114盤點支數（目標寫入欄位）**
   - Column T：**盤差（目標填寫公式 `=S{row}-N{row}`）**
2. **現場盤點量表 (如 `2F訂單.xlsx`)**：
   - 工作表名稱：`Sheet1`
   - 欄位包括：`產品代碼`、`規格`、`長度(M)`、`實際訂購量`（現場清點支數）、`備註`（現場儲位）。

## 🚀 觸發時機與對話流程
當使用者：
- 詢問或上傳關於「立達鋼鐵」、「2F盤點」、「盤盈虧核算」、「2F庫存」、「2F訂單」等資料時。
- 或說「幫我對看看這兩個盤點檔」、「核算盤盈虧」時。

**AI 回覆規範**：
1. 立即呼叫 `reconcile_core.py` 進行核算。
2. 簡潔回報：全廠比對總項數、完全吻合項數、差異項數（多開幾項、少開幾項）。
3. 直接提供生成的 Excel 點擊連結，並附上給文欣的貼心白話說明。
