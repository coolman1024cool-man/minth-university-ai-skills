## 🔍 各項技能詳細說明

### 1. 🧾 ALLTOP 核銷機器人 (`alltop-expense-bot`)
* **主要用途**：自動化行政核銷流程。
* **輸入方式**：上傳實體收據、發票照片或 PDF。
* **輸出結果**：符合 ALLTOP 格式的核銷 Excel 清冊。

### 2. 📑 ALLTOP 採購小幫手 (`alltop-purchasing-bot`)
* **主要用途**：採購詢價與規格表自動化。
* **輸入方式**：上傳廠商報價單截圖或檔案。
* **輸出結果**：產出 RPA 快速上機表與 A2 規格比對表。

### 3. 🎨 敏實海報生成器 (`minth-poster-generator`)
* **主要用途**：敏實科大專屬活動與 USR 成果宣傳海報。
* **特色規格**：內建敏實科大高解析 Logo、支援四大成果卡片排版、底部自動生成行政資訊欄。
* **輸出格式**：可直接匯入 Canva 保持圖層完全可編輯的 `.pptx` 檔。

### 4. 📊 USR 預算報表轉換器 (`usr-budget-report-formatter`)
* **主要用途**：校務計畫與 USR 經費管考報表。
* **排版規範**：嚴格符合國家公文標準（標楷體、細黑實線、A4 直式單頁、數字欄位絕對不折行）。

### 5. 📅 智慧行事曆小幫手 (`smart-calendar-assistant`)
* **主要用途**：行程萃取與行事曆自動排程。
* **支援分類**：私人行程、USR 計畫、家庭行程。
* **輸出結果**：透過 Google Calendar API 直接寫入您的雲端行事曆。

### 6. 👥 工讀金資料彙整工具 (`work-study-data-compiler`)
* **主要用途**：整合跨期工讀金紀錄。
* **智慧補齊**：結合歷史資料庫，自動填補缺漏之身分識別資料。

### 7. 🌐 全球局勢戰略顧問 (`global-context-strategist`)
* **核心視角**：以台灣立足點出發，深度剖析國際大事、美中角力、貨幣政策與供應鏈變革。

### 8. ⚡ 全球能源分析專家 (`energy-expert`)
* **核心領域**：再生能源、核能、地質探勘、電網穩定性與國際減碳趨勢。

### 9. 🏛️ 歷史與宗教研究專家 (`religious-studies-researcher`)
* **核心領域**：文化資產、寺廟建築、宗教民俗流變與文獻考證。

### 10. 📝 USR 活動記錄表生成器 (`activity-record-generator`)
* **主要用途**：自動化生成敏實科大 USR 計畫官方「課程教學及活動記錄表」Word (.docx) 檔。
* **特色規格**：
  * 完美保留官方頁首校徽 Logo、酒紅色分隔線與左側「裝 訂」邊界標記。
  * 自動核選子計畫方塊、填寫主持人/工讀生、時間地點與與會者。
  * 支援量化人次/問卷調查、質化效益評估、四段式結構化活動紀要與檢討建議。
  * 活動剪影自動將 2～6 張照片等比例縮放嵌入（防變形、居中對齊），自帶圖說文字與附件勾選。
  * 可選擴充全頁簽到表掃描檔與宣傳海報附錄頁。
* **產出命名**：自動附加民國年月日時分（11碼）與 `-anti.docx`，預設存入 `Gemini_Spark_產出檔案`。

## 📥 如何將技能分享給他人使用？

1. **分享單一技能**：將特定技能資料夾（如 `minth-poster-generator`）壓縮為 ZIP 檔傳給對方。
2. **對方安裝方式**：
   * 將資料夾解壓縮後放入電腦的技能目錄：`C:\Users\<使用者名稱>\.gemini\config\skills\`
   * 重啟 AntiGravity / Gemini IDE 即可直接使用！
